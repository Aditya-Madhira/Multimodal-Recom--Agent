# Multimodal Recommendation Agent

An agentic Multimodal Retrieval-Augmented Generation (RAG) system for intelligent recommendations across text and visual modalities.

## Overview

This project implements an end-to-end multimodal recommendation agent combining:
- **Multimodal Embeddings & Search**: Vector indexing and retrieval across text and visual data.
- **Agentic Workflow**: Goal-driven reasoning and recommendation orchestration.
- **Contextual Synthesis**: Rich, personalized responses powered by Vision-Language Models (VLMs).
